# Wavelength

AI-powered conversational coach for building real communication confidence.

Wavelength lets users practice real conversations (professional and personal) with a voice-based AI persona that behaves like a real person, pushing back, adapting, and shifting based on how well the user communicates. Sessions end with evidence-based feedback and a score, and progress is tracked across sessions to show measurable growth.

## Team structure

This repo is organized around 5 teams, each with its own folder and branch:

| Team | Folder | Branch |
|---|---|---|
| Product & Research + Project Management | `product-research/` | `team/product-research` |
| Design + Frontend/App Development | `design-frontend/` | `team/design-frontend` |
| AI/Prompt Engineering | `ai-prompt-engineering/` | `team/ai-prompt-engineering` |
| Voice/Tech Infrastructure | `voice-tech-infra/` | `team/voice-tech-infra` |
| Backend Development | `backend/` | `team/backend` |

## Workflow

1. Work on your team's branch (`team/<team-name>`)
2. Open a PR into `main` when ready for review
3. Keep team-specific work inside your team's folder to avoid merge conflicts across teams
